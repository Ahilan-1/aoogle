Changelogs

Every update to arlong, from the beginning.
v1.0

Initial release

July 2025
  • NEW Meta search engine - Pulls results from DuckDuckGo and Bing, re-ranked by a transparent multi-factor scoring algorithm.
  • NEW 80+ bang shortcuts - Type !g python to search Google, !wiki Python for Wikipedia, !re python for Reddit, and more.
  • NEW Multi-factor result scoring - Every result ranked by title match, snippet relevance, domain authority, content quality, freshness, category relevance, URL quality, and more.
  • NEW AI content detection - Automatic detection and penalization of AI-generated, keyword-stuffed, and low-effort content.
  • NEW Content quality filters - Filter results by General, Tutorials, Discussions, Documentation, or News.
  • NEW Knowledge panels - Wikipedia-based info boxes for people, places, and topics.
  • NEW Live stats dashboard - Real-time search activity at /stats.
  • NEW No-logging architecture - Zero query logging, zero IP storage, zero cookies. Designed so compliance with data requests is technically impossible.
  • NEW Zero tracking - No Google Analytics, no Facebook Pixel, no fingerprinting, no session recording.
  • NEW Dark mode - Toggle with the moon/sun button in the top-right corner.
  • NEW Image search - Search images via Bing at /images.
  • NEW Video search - Search videos via DuckDuckGo and YouTube at /videos.
  • NEW Autocomplete suggestions - Real-time search suggestions as you type.
  • NEW Bang autocomplete - Type ! to see and select from 80+ bang shortcuts with favicons.
  • NEW Manual site submission - Submit your website for manual review at /submit.
  • NEW Transparent scoring - Every result shows its category and quality score. See how it works.
  • NEW Free API with keys - Tokenless search at 2 req/hour, or 80 req/30min with a free key from /api/dashboard. Docs at /docs.
  • NEW Crisis detection - Queries expressing self-harm or suicidal ideation return crisis resources.
  • NEW NSFW filtering - Adult content queries are blocked and redirected to support resources.
  • NEW Result reporting - Report low-quality results via the three-dot menu on any result.
  • NEW Admin dashboard - Manage reports, blacklist domains, and view stats.
  • NEW Browser extensions - Chrome and Firefox extensions available for quick access.
  • NEW Reddit boost - Real Reddit threads get a relevance boost on discussion-type queries.
