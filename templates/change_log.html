Changelog

Concise, technical notes on what changed with each release of arlong. No fluff, no hype — just the facts.

v2.0.0 Full private, API keys, and the new places layer 2026-08-04

New

  • NEW Registered API access. Sign up, accept the Terms of Service, and get an API key granting 80 requests per 30 minutes per project.
  • NEW API dashboard. Manage, regenerate, and revoke your key, and view live usage stats at /api/dashboard.
  • NEW Places results. "Near me" queries now surface local businesses with ratings, hours, photos, and directions.
  • NEW Redesigned result cards. Cleaner layout, uniform borders, tighter radii, and inline nested video previews.
  • NEW Blogging. Anyone with an account can write and publish blog posts on arlong.
  • NEW Onboarding tour. New accounts get a short feature tour on their first visit.

Changed

  • CHANGE Licensing: open source → "All rights reserved." arlong is now fully private and proprietary — the source code is no longer publicly accessible. Rationale: protecting the ranking algorithm and preventing infrastructure abuse of the public service.
  • CHANGE API rate limits. Tokenless access is now capped at 2 requests per hour per IP (previously 125/hr). Full quota requires an API key. Requests beyond the tokenless cap return a 429 with a "Get a API KEY" response.
  • CHANGE Terms of Service & Privacy Policy updated to cover API keys, usage data retention, the license change, and liability terms.
  • CHANGE Signup flow now requires accepting the Terms of Service and issues an API key automatically.
v1.x Earlier releases 2025 — 2026

Highlights

  • Initial release — meta-search engine with multi-factor scoring, 80+ bangs, image and video search, and zero-logging architecture.
  • Places infrastructure — Google Places and Serper-backed local business data pipeline with photo proxy and caching.
  • Image search improvements — full-resolution viewer and refresh button.
  • Nested video previews — inline YouTube groups with scroll-spy thumbnails, save overlay, and duration badges.
  • Community — collections, blogs, verified businesses, and daily encrypted backups.
