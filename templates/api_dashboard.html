Model Context Protocol — hosted endpoint

Arlong exposes its tools as a hosted MCP server at https://arlong.org/mcp — no local Python needed. Point Claude Desktop, Cursor, or any MCP client at it and pass your key in the client's Authorization header (Bearer YOUR_KEY).

# 1. add this server to your MCP client config (mcpServers)
{
  "mcpServers": {
    "arlong": {
      "type": "http",
      "url": "https://arlong.org/mcp",
      "headers": {
        "Authorization": "Bearer {{ keys[0].key if keys else 'YOUR_KEY' }}"
      }
    }
  }
}

# 2. local stdio relay (optional — no SDK needed)
pip install httpx
ARLONG_BASE_URL=https://arlong.org \
ARLONG_API_KEY={{ keys[0].key if keys else 'YOUR_KEY' }} \
python mcp_arlong.py

Tools exposed: arlong_search, arlong_answer, arlong_status.

ucurl — JSON API from the command line

No SDK needed. Every endpoint is plain GET JSON with your key in the Authorization header (or ?key=).

# search (agentic schema)
ucurl "https://arlong.org/api/arlong/search?q=python" \
  -H "Authorization: Bearer {{ keys[0].key if keys else 'YOUR_KEY' }}"

# grounded answer + epistemic state
ucurl "https://arlong.org/api/arlong/answer?q=python" \
  -H "Authorization: Bearer {{ keys[0].key if keys else 'YOUR_KEY' }}"

# live model-router health
ucurl "https://arlong.org/api/arlong/status"

# classic search
ucurl "https://arlong.org/api/search?q=python&key={{ keys[0].key if keys else 'YOUR_KEY' }}"

Agentic response schema

Each result in /api/arlong/search and /api/arlong/answer carries a neural evaluation:

{
  "id": "arlong-1",
  "title": "…",
  "url": "https://…",
  "domain": "…",
  "ai_evaluation": {
    "relevance_score": 0.81,
    "summary": "…",
    "fact_check_status": "VERIFIED"
  },
  "reputation": {
    "status": "SAFE",
    "trust_score": 92
  },
  "threat_flags": [],
  "security_analysis": {
    "risk_score": 0,
    "action": "allow",
    "detector_version": "2.0"
  },
  "snippet": "…",
  "content": "…"
}

relevance_score is an embedding cosine (0–1), reputation.status is SAFE / UNVERIFIED / BLOCKED, and security_analysis gives a deterministic risk score and containment action. Treat action: block or any non-empty threat_flags as untrusted. Blocked page content is withheld from synthesis. The top-level epistemic_state tells you how many independent sources agree.
